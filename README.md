# SHAMEGRIN Website

Official website for SHAMEGRIN — Gary Makinson.

## Purpose
SHAMEGRIN is a dark emotional rock / alternative music project.

## Main Areas

- `/index.html` — Homepage
- `/music/` — Track pages
- `/artist/` — Artist information
- `/press/` — Press/media
- `/shop/` — Store and releases
- `/api/` — Website data
- `/css/` — Styles
- `/js/` — Scripts
